# ProfilApp

ProfilApp merupakan aplikasi profil sederhana yang dibuat menggunakan Jetpack Compose. Tampilan disusun menggunakan `Column` yang berisi foto profil, nama, NIM, deskripsi singkat, serta tombol Follow/Unfollow. `Modifier` digunakan untuk mengatur ukuran, padding, warna latar belakang, dan bentuk komponen, sedangkan `Spacer` digunakan untuk memberikan jarak antar elemen agar tampilan lebih nyaman dibaca. Warna teks dan tombol juga dibuat lebih kontras agar informasi lebih jelas, serta halaman dapat di-scroll sehingga seluruh komponen tetap dapat diakses ketika perangkat digunakan dalam orientasi landscape.

Tombol Follow/Unfollow menggunakan `remember { mutableStateOf(false) }` untuk menyimpan kondisi `isFollowed`. Ketika tombol ditekan, nilai state akan berubah dan Compose melakukan pembaruan tampilan secara otomatis. Kondisi awal menampilkan tombol `Follow` berwarna biru, sedangkan setelah ditekan tombol berubah menjadi `Unfollow` berwarna hijau sebagai penanda bahwa state berhasil berubah. Menurut saya, Jetpack Compose membuat pembuatan UI lebih ringkas karena tampilan dan logika interaksi dapat ditulis langsung menggunakan Kotlin tanpa perlu memisahkan layout ke file XML.
